# Codex Limit Bar for Windows

Небольшой виджет для Windows, который показывает текущие лимиты использования Codex: 5-часовой и недельный лимит, оставшийся процент и время до сброса.

Приложение работает локально через Codex `app-server` и не отправляет дополнительные промпты модели.

## Установка

Для обычного использования установка не требуется.

1. Скачайте `CodexLimitBar.exe`.
2. Запустите файл.
3. При необходимости включите автозапуск через меню приложения.

Программа является self-contained Windows-приложением.

---

## Требования

- Windows 10 или Windows 11 x64
- установленный Codex
- пользователь должен быть авторизован в Codex

Приложение протестировано с Codex для Windows, установленным из Microsoft Store.
