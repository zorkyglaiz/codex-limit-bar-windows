# Codex Limit Bar for Windows

Небольшой виджет для Windows, который показывает текущие лимиты использования Codex: 5-часовой и недельный лимит, время до их сброса и оставшийся процент.

Работает локально через Codex `app-server` и не отправляет дополнительные промпты модели.

## Возможности

- 5-часовой лимит Codex
- недельный лимит
- время до сброса лимита
- автоматическое обновление
- системный трей Windows
- всплывающая полная панель
- компактный мини-виджет
- режим «Поверх всех окон»
- прозрачность окна от 10% до 100%
- запуск вместе с Windows
- сохранение настроек
- цветовая индикация оставшегося лимита

## Режимы отображения

### Полная панель

Показывает:

- процент оставшегося 5-часового лимита
- время до его сброса
- недельный лимит
- дату и время сброса недельного лимита
- время последнего обновления

### Мини-виджет

Компактный режим для постоянного отображения поверх окон.

Крупно показывает 5-часовой лимит, а ниже - недельный остаток.

### Системный трей

При наведении на иконку отображается краткая информация о текущих лимитах.

Через меню трея можно:

- открыть полную панель
- открыть мини-виджет
- свернуть приложение в трей
- включить режим «Поверх всех окон»
- изменить прозрачность
- обновить данные
- включить автозапуск
- выйти из приложения
